# CITS Message Specs

This directory contains CSV files for each message type used between commercial banks and the clearing hub in the CITS project. Each CSV lists fields with data type, max length, whether required, a brief description and an example value.

Files created:

- Capture_Batch_Submission.csv
- Immediate_Receipt_ACK_NACK.csv
- Batch_Processing_Result.csv
- Image_Validation_Detail.csv
- Reject_Return_Notice.csv
- Clearing_Settlement_Instruction.csv
- Funding_Movement_Instruction.csv
- Settlement_Confirmation.csv
- Reconciliation_File.csv
- Return_Recall_Claim.csv
- Inquiry_Status_Request.csv
- File_Manifest.csv
- Heartbeat_HealthCheck.csv
- Certificate_Exchange.csv
- Operational_Alert_Incident_Notification.csv
- Test_File_Certification.csv
- Audit_Log_Export.csv
- Fraud_Alert.csv
- Chargeback_Adjustment_Notice.csv
- Configuration_Update.csv
- Bulk_Archive_Retrieval_Request.csv

To import into Excel: File -> Open -> select the CSV files, or in Excel use Data -> From Text/CSV to import and set delimiter to comma.
