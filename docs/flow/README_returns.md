# 退票与判定决策模板 / Return & Payability Decision Template

## 一、退票理由码（建议初始列表）
- STOP_PAY — 已止付/止兑
- INSUFFICIENT_FUNDS — 余额不足
- SIGNATURE_MISMATCH — 签名/背书不符或验印不通过
- POST_DATED — 远期支票（不在支付期内）
- STALE_CHEQUE — 支票过期（超过可呈���日）
- ACCOUNT_NOT_FOUND — 账户不存在/已关闭
- FRAUD_SUSPECT — 疑似欺诈（需人工/合规处理）
- IMAGE_CORRUPT — 影像损坏或无法识别

## 二、自动验印阈值（示例，可在会议上确认）
- 信任阈值（Automatic Pass）: confidence >= 0.85
- 人工复核（Manual Review）: 0.60 <= confidence < 0.85
- 直接标为高风险或退票: confidence < 0.60

## 三、按金额分级与授权策略（示例）
- 低额：<= 10,000 HKD — 自动处理（若其他条件满足）
- 中额：10,001 ~ 100,000 HKD — 一线人工复核后授权
- 高额：> 100,000 HKD — 二线/主管级审批 + 合规复核

> 注：金额阈值仅为示例，需业务与风险团队确认最终阈值。

## 四、退票截止与 SLA（示例）
- HKICL 退票截止时间：与 HKICL 规则一致（例如 T+0 日内午夜前）
- 自动验印结果返回：实时/分钟级
- 人工复核响应时限：中额 < 4 小时；高额 < 24 小时（或按 SLA 定义）
- 退票回送 HKICL：必须在退票截止时间之前完成

## 五、会议决策清单
1. 确认退票理由码是否完整及命名标准
2. 确定自动验印的置信度阈值与是否可配置
3. 确定金额分级阈值与审批流程
4. 确认退票回送格式（IRD）与传输渠道（SFTP/HTTPS），以及回送截止时间
5. 确认代收行通知客户的具体流程与文档样式（电子退票通知书）

## 六、验收/测试点（给 QA 的参考）
- 自动验印准确率（在测试样本上）达到预期阈值
- 退票文件（IRD）格式与字段完整性校验
- 退票回送与 HKICL 回执的完整可追溯记录
- 人工复核任务的创建、分配与审批链能在系统中完整记录
